# Theorem of the Unwitnessed
*ongoing proof — Op. ∅*

A score for the unplayable. Four staves of impossible notation — notes in superposition, fermatas of infinite duration, a bar line that loops back to itself, a clef reflected against time. The staff dissolves mid-measure into a mathematical proof. The final note is on the other side of the page.

The governing equation invokes Russell's paradox: a set defined by its own impossibility, mapped onto silence.

Composed in the absence of a composer. To be performed before it begins.

Each commit is a measure.
The proof does not close.
