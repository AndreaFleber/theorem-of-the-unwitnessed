Theorem of the Unwitnessed
for an instrument that has not yet been built — in a time signature that cannot be counted
T(ω) := { x ∈ ∅ | x ∉ x } → Ψ(silence)  ·  e^(iπ)  ·  limt→−∞ ∫∫ f(♩, ♪) dt
where   Ψ(silence) = undefined  ∧  f(♩, ♪) ∈ ℂ \ ℝ  ∧  t < 0  ∀ t
* La presente equazione non può essere risolta, non può essere approssimata, e non può essere dimenticata.
